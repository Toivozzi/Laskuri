<strong>Yksinkertainen laskuri, joka laskee matemaattisia laskuja.<strong/>

## Ominaisuudet

### LASKURI
- Yhteenlasku (`+`)
- Vähennyslasku (`-`)
- Kertolasku (`*`)
- Jakolasku (`/` tai `:`)
- Potenssit (`^`)
- Sulkeet (`()`)
- Tuloksen pyöristäminen valitulla desimaalien määrällä

### Ajastin
- Ajastin alaspäin
- Alastin ylöspäin

### Joululaskuri
- Näet kuinka kauan on vielä jouluun.

## Kuinka käytän Laskuria???
Lataa source koodi tai käytä suoraan [Laskuri](https://toivozzi.github.io/laskuri/)
```text
1. Avaa GitHub-repo - https://github.com/Toivozzi/laskuri

2. Paina Code -> Download ZIP

3. Pura ladattu ZIP-tiedosto kansioon

4. Avaa purettu kansio

5. Etsi index.html

6. Tuplaklikkaa index.html-tiedostoa
```

### Esimerkkejä laskuista:

```text
5+5
10*4
5545:545
2^8
(5+3)*2
```
