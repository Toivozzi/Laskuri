Laskuri - Laske laskusi nopeasti ja vaivattomasti!

<strong>Yksinkertainen laskuri, joka laskee matemaattisia laskuja.<strong/>

## Ominaisuudet

### LASKURI
- Yhteenlasku (`+`)
- Vähennyslasku (`-`)
- Kertolasku (`*`)
- Jakolasku (`/` tai `:`)
- Potenssit (`^`)
- Sulkeet (`()`)
- Tuloksen pyöristäminen valitulla desimaalien määrällä

### Ajastin
- Ajastin alaspäin
- Alastin ylöspäin

### Joululaskuri
- Näet kuinka kauan on vielä jouluun.

## Käyttö

Avaa laskurin nettisivu.

### Esimerkkejä laskuista:

```text
5+5
10*4
5545:545
2^8
(5+3)*2
```
